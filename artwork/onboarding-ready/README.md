# Onboarding artwork

Use `website/public/art/` as the canonical local image source and handoff folder.
The website serves these images at `https://redkeep.lewiseman.com/art/` and the
mobile catalog selects the required files. No additional copy in this folder or
`assets/reference/`, Firebase URL list or separate download pack is needed.

See [asset setup](../../docs/onboarding-assets-setup.md) for adding artwork,
metadata and offline checks. `raw_assets/` stays the user's untouched work area.
