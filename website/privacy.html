Privacy policy

Your journal is yours.

A clear description of this website and the current Redkeep build.

Your writing

The current Redkeep mobile build stores Notes, Diary and Flow writing and settings locally. This website is a product tour: you cannot write or upload journal entries here.

Optional assistance and downloads

Grand Maester uses an optional model on the device after setup. Required artwork, optional models and the mobile onboarding caption font may need network access. Download providers receive normal connection information. This website serves its own artwork and fonts locally.

This website

There are no accounts, analytics, advertising or cookies used by this website. If you write your name on the book cover, it is saved only in your browser and remains when you reopen this site. Clearing site data removes it. If browser storage is blocked, you can still enter a name for the current page visit. The gallery buttons change only the current page. The web host may receive ordinary request information, including IP address and browser details. The production host has not been selected.

External links

Following the source link opens GitHub, which has its own privacy policy. No external service is contacted until you follow an external link.

Before publication

This policy describes the local W01 website and current build. It must be reviewed against the chosen production host and the final distributed app before publication.
